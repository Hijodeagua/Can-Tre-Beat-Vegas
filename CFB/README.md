# College football model

Built against the pulls described in `DATA_PULL_PLAN.md`. Current state:
**Tier 0 complete** — full 26-season history ingested, FCS pooled, and the
§8 Elo constants **fitted by grid search** rather than guessed.

## Layout

```
CFB/
├── DATA_PULL_PLAN.md   # the shopping list — what to pull from CFR and why
├── ingest.py           # raw CFR exports -> tidy aggregates
├── elo.py              # base head-to-head Elo, FCS pooled, fitted constants

│   ├── 2000-games.csv … 2025-games.csv        # 26 season schedules

│   └── def_stats_*.csv                        # same, defense side
└── agg/                # everything below is regenerated by the scripts
    ├── cfb_games.csv                  # game spine, home perspective, 21,300 games
    ├── cfb_offense_team_season.csv    # 3,240 team-seasons
    ├── cfb_defense_team_season.csv    # 3,240 team-seasons
    ├── cfb_elo_ratings.csv
    └── fit_grid.csv                   # every grid-search config, ranked
```

Rebuild everything:

```bash
python3 -m CFB.ingest --validate
python3 -m pytest tests/test_cfb_ingest.py tests/test_cfb_elo.py
python3 -m CFB.elo
python3 -m CFB.fit --refine        # re-fit the constants
```

## Data status

Full Tier 0 in `raw/`: 26 season schedules (2000-2025, **21,300 games** after
dedupe) plus the complete FBS scoring/defense universe (3,240 team-seasons
each after dropping zero-game placeholder rows — 2026 stubs and the two 2020
COVID opt-outs, Connecticut and Old Dominion). Per-season FBS counts track
expansion exactly: 116 teams in 2000 → 136 in 2025.

## The Winner/Loser transform

CFR schedules list the *winner* first with a location marker: blank = winner
was home, `@` = winner was on the road, `N` = neutral. `ingest.py`
reconstructs home/away; `tests/test_cfb_ingest.py` pins the transform, and
`--validate` prints the aggregate check. Full-history home win rate on
non-neutral games: **63.0%** (0.59-0.65 by season; 2020 lowest at 0.592 —
COVID crowds) — higher than the NFL's ~57% because of buy games, and the
right sign (an inverted transform would read ~37%).

## Parser gotchas found on the full pull (all fixed, all tested)

1. **2016-2019 exports carry a venue string on every game** ("Lane Stadium -
   Blacksburg Virginia"), which the old any-note-means-bowl rule classified
   as postseason (~880 "bowls" per season). `_game_type` now strips the
   parenthesised venue, treats remaining `" - "` strings as venues, and
   requires a Dec/Jan date — which also keeps August "Kickoff Classic" games
   and the October Red River game (played *at* the Cotton Bowl stadium)
   regular-season. 1,033 postseason games across the pull.
2. **CFR double-lists some bowls** — once with the bowl name, once with the
   venue string (24 across the pull). `dedupe_games` keeps the
   postseason-classified row.
3. **Stat pages and schedules disagree on school names.** Schedules spell
   out `Louisiana State`, `Southern California`, `Central Florida`,
   `Brigham Young`…; stat pages abbreviate to `LSU`, `USC`, `UCF`, `BYU`.
   13 schools are affected (list printed by `CFB.elo`) — this is the raw
   material for the plan §3.3 crosswalk, and until that exists the
   schedule-side names are canonical for game data while stat-side joins
   need the alias map.
4. **Schema drift**: 2000-2012 exports have no kickoff-time column; 2013+
   do. Handled by column-name lookup rather than position.

## FCS pooling (plan §3.4)

`elo.pool_fcs` replaces every non-FBS opponent with one synthetic **FCS**
team. FBS membership per season = listed in the offense scoring aggregate
**or** 5+ schedule games that season — the second clause is what keeps the
name-mismatched schools above out of the pool (a real FCS opponent appears
in at most a handful of games in these FBS-only exports; a mismatch-named
FBS school plays a full slate). Result: the pooled team went **198-2207 vs
FBS (8.2%)** at a final rating of ~810 — right where a buy-game aggregate
should sit. `--no-pool` restores individual ratings. Known accepted flaw:
North Dakota State and an FCS bottom-feeder are the same team to the pool.

## Fitted constants (CFB.fit, walk-forward log loss on 2005+)

| Parameter | NFL | Plan §8 guess | **Fitted** |
|---|---|---|---|
| K | 20 | 20-40 | **35** |
| HFA (Elo) | 55 | 65-80 | **50** — but at 18.6 Elo/pt that's **~2.7 points**, more than the NFL's ~2.2, as predicted |
| Season regression | 0.25 | 0.35-0.50 | **0.20** — the churn hypothesis was wrong; high K re-sorts ratings fast enough that gentler carryover wins |
| Margin cap | none | 28-35 | **none** — every capped config graded worse; log MOV damping suffices |
| Elo per point | 25 | 27-32 | **18.6** (margin regression) |

The surface is flat near the optimum (anything in K 32-35 / HFA 45-60 /
regression 0.15-0.25 is within 0.0003 log loss), so these are stable. Full
ranked grid: `data/college_football/agg/fit_grid.csv`.

## Results (fitted constants, FCS pooled)

Walk-forward pregame win probabilities, ratings warmed up from 2000:

- **2005+ (17,622 games): log loss 0.5079, accuracy 74.2%**
- All seasons (21,300): 0.5095 / 74.2%

Not comparable to the NFL numbers (~0.63 log loss) — CFB has cupcake
blowouts the NFL doesn't, which any rating system calls correctly. The
honest yardstick will be the market (§7) and SRS (§3.1) once those are in.

End-of-2025 board top 10: Indiana, Ohio State, Miami (FL), Notre Dame,
Georgia, Oregon, Mississippi, Texas, Texas Tech, Utah — a sane list, from
scores alone.
