# College football model

Built against the pulls described in `DATA_PULL_PLAN.md`. Current state:
**Tier 0 pipeline working**, validated on the 2000 season plus the two
scoring-stat pulls (2002-2025 samples).

## Layout

```
CFB/
├── DATA_PULL_PLAN.md   # the shopping list — what to pull from CFR and why
├── ingest.py           # raw CFR exports -> tidy aggregates
└── elo.py              # base head-to-head Elo on the normalised spine

data/college_football/
├── raw/                # CFR exports, committed as-is, never edited
└── agg/                # everything below is regenerated by the scripts
    ├── cfb_games.csv                  # game spine, home perspective
    ├── cfb_offense_team_season.csv
    ├── cfb_defense_team_season.csv
    └── cfb_elo_ratings.csv
```

Drop new CFR exports into `raw/` — schedule files matching `*games*.csv` or
`*schedule*.csv`, scoring pages matching `*pts_stats*.csv`, defense pages
matching `*def_stats*.csv` — and re-run:

```bash
python3 -m CFB.ingest --validate
python3 -m CFB.elo
python3 -m pytest tests/test_cfb_ingest.py
```

## The Winner/Loser transform

CFR schedules list the *winner* first with a location marker: blank = winner
was home, `@` = winner was on the road, `N` = neutral. `ingest.py`
reconstructs home/away; `tests/test_cfb_ingest.py` pins the transform, and
`--validate` prints the aggregate check. On the 2000 season: **home teams won
62.9% of non-neutral games** — higher than the NFL's ~57% because of buy
games, and the right sign (an inverted transform would read ~37%).

Spot checks that came back correct: #7 Miami hosting #1 Florida State
27-24 (Wide Right III), and the Orange Bowl parsed as neutral-site with
Oklahoma 13, FSU 2.

Constants are the plan's §8 starting guesses (K=32, HFA=70, regression 0.40,
margin capped at 35, ~28 Elo/point), reusing the NFL `EloEngine`. Untuned.

Five of Elo's top seven are the AP's top six, from nothing but scores —
with every team starting the season at a flat 1500. Pregame probabilities
graded 72.8% / 0.573 log loss over 702 games, flattered by cupcake
blowouts and not comparable to the NFL numbers; multi-season walk-forward
evaluation needs the full 2000-2025 schedule pull.
